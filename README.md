АПІ для вигаданого магазина. 
Містить в собі взаємодію з користувачами, продуктами та транзакціями між ними.
Python, PostgreSQL, FastApi ..
# Функціонал:
## Користувачів
1) Додавання нових користувачів в БД через post запит */user*.
2) Редагування інформації через patch запит */user/{user_id}*
3) Видалення користувача через delete */user/{user_id}*
4) Отримання інформації про користувачів get */user* / */user/?user_id={user_id}*
## Товарів
1) Додавання через post */products/add*
2) Перегляд наявних товарів через  get */products/*
3) Редагування інформації про товар через patch */products/{barcode}*
4) Видалення товарів через delete */products/{barcode}*
## Транзакцій
1) Додавання нової транзакції(з перевіркою на можливість, кілкість товару / достатня кількість грошей) через post */transactions/new*
2) Перегляд всіх транзакцій / транзакцій користувача через */transactions/show* / *transactions/show?buyer_id=2*
